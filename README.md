# 📊 Economic Data Science Portfolio

Welcome to my repository for **ECON 3916: Statistical & Machine Learning for Economics**! This collection showcases my journey in bridging traditional economic theory with modern data science methods.

## 👋 About Me

I'm an undergraduate economics student passionate about applying quantitative methods to real-world economic problems. I'm actively seeking opportunities in **Economic Consulting**, where I can leverage both econometric rigor and machine learning techniques to generate actionable insights.

I believe the future of economics lies at the intersection of causal inference and predictive analytics—and this portfolio reflects my commitment to mastering both.

## 📚 About This Portfolio

This repository contains coursework, labs, and projects from my Statistical & Machine Learning course. The materials here demonstrate my ability to:

- Apply **causal inference** frameworks to economic questions
- Scale traditional statistical methods using **machine learning algorithms**
- Translate economic theory into data-driven solutions

### Course Philosophy: Concept Extension

Our approach takes foundational statistical concepts—like linear regression—and extends them into powerful machine learning tools—like Lasso and Ridge regression. This philosophy allows me to understand *why* methods work, not just *how* to implement them, ensuring I can adapt techniques to novel economic problems.
